# Презентация защиты диплома

## Тема: Методы повышения инвариантности к сдвигам в сверточных нейронных сетях для задач компьютерного зрения

Данная презентация создана на основе содержания дипломной работы и рассчитана на **20 минут** защиты.

## Структура презентации

### 1. Введение (3-4 минуты)
- Актуальность проблемы инвариантности к сдвигам в CNN
- Цель и задачи исследования

### 2. Теоретические основы (4-5 минут)
- Математическая формализация проблемы
- Алиасинг как источник нарушения инвариантности
- Эквивариантность vs инвариантность

### 3. Методы решения (4-5 минут)
- BlurPool: антиалиасинг через низкочастотную фильтрацию
- TIPS: полифазная выборка с инвариантностью к сдвигам

### 4. Экспериментальная часть (2-3 минуты)
- Используемые датасеты и методология
- Модифицированные архитектуры (VGG16, ResNet50, YOLOv5)

### 5. Результаты (4-5 минуты)
- Результаты для классификации
- Результаты для детекции объектов
- Вычислительная эффективность

### 6. Практические рекомендации (1-2 минуты)
- Рекомендации по выбору методов для различных приложений

### 7. Заключение (1-2 минуты)
- Основные результаты и выводы

## Ключевые результаты

### Классификация
- **Улучшение стабильности**: 7.5-10.7 процентных пунктов
- **Повышение точности**: 1.3-2.1 п.п.
- **TIPS превосходит BlurPool** по всем метрикам

### Детекция объектов
- **IoU Stability**: улучшение на 6.8-11.1 п.п.
- **Center Drift**: снижение в 2+ раза
- **Особенно эффективно для малых объектов**: до 2.6 п.п. прироста

### Вычислительная эффективность
- **BlurPool**: <1% дополнительных FLOPs
- **TIPS**: 2-5% дополнительных FLOPs
- Пригодны для систем реального времени

## Практические рекомендации

### Системы критического применения
- **Рекомендация**: TIPS
- Медицинская диагностика, автономное вождение
- Максимальная стабильность (97-98% консистентности)

### Системы с ограниченными ресурсами  
- **Рекомендация**: BlurPool
- Мобильные приложения, встраиваемые системы
- Существенное улучшение при минимальных затратах
