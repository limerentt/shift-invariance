\section{Экспериментальные результаты}
\label{sec:results} \index{Chapter4}

В данном разделе представлены основные результаты применения методов повышения инвариантности к сдвигам для задач классификации и детекции объектов. Проведено комплексное сравнение базовых архитектур и их модификаций, использующих методы BlurPool и TIPS.

\subsection{Инвариантность к сдвигам для задач классификации}
\label{ssec:classification_results}

В экспериментах с классификационными моделями оценивалась эффективность применения методов антиалиасинга для архитектур VGG16 и ResNet50. Для каждой базовой архитектуры были созданы две модификации — с применением BlurPool (см. раздел \ref{review:antialias:blurpool}) и TIPS (см. раздел \ref{review:antialias:tips}) соответственно. Теоретические основы проблемы инвариантности к сдвигам и принципы работы этих методов подробно рассмотрены в главе \ref{review}.

\begin{note}
В исследовании для экспериментов использовались уменьшенные версии датасетов: ImageNet-mini и COCO-sample. Данный выбор обусловлен значительными вычислительными требованиями при проведении множественных экспериментов с различными модификациями архитектур и необходимостью многократных прогонов каждой модели для анализа инвариантности к сдвигам (до 100 прогонов для каждого изображения с различными субпиксельными сдвигами). При этом статистический анализ показал, что уменьшенные выборки сохраняют репрезентативность и позволяют сделать обоснованные выводы о свойствах инвариантности моделей. Для подтверждения масштабируемости результатов были проведены дополнительные выборочные эксперименты на полных датасетах, которые подтвердили схожие тенденции.
\end{note}

В таблице (см. Таблица \ref{tab:classification_models}) демонстрируется сравнительная оценка базовых моделей и их модификаций с применением методов антиалиасинга на датасете ImageNet-1k. В качестве основных метрик использовались:

\begin{itemize}
    \item Top-1 Accuracy — точность классификации по верхнему предсказанию;
    \item Stability — метрика стабильности предсказаний при небольших сдвигах изображения (0-5 пикселей), определение которой приведено в разделе \ref{review:invariance};
    \item Consistency — консистентность предсказаний между оригинальным и сдвинутым изображением;
    \item Flip-Invariance — устойчивость к горизонтальному отражению изображения.
\end{itemize}

Таблица \ref{tab:classification_models}), применение методов антиалиасинга приводит к одновременному улучшению как точности классификации, так и консистентности предсказаний при сдвигах. Особенно заметно улучшение по метрике стабильности (Stability), где наблюдается увеличение на 7.5-10.7 процентных пунктов. Метод TIPS демонстрирует более высокие значения по всем метрикам по сравнению с базовыми моделями и модификациями с BlurPool.

\subsection{Стабильность детекции объектов}
\label{ssec:detection_results}

Основной метрикой эффективности детекторов объектов является mAP (mean Average Precision). В таблице (см. Таблица \ref{tab:detection_results}) представлены результаты сравнения базовой модели YOLOv5s с модифицированными версиями, включающими методы антиалиасинга.

\begin{table}[h]
\centering
\begin{tabular}{|l|c|c|c|c|}

Как видно из таблицы (см. Таблица \ref{tab:detection_results}), применение методов антиалиасинга приводит к улучшению всех ключевых метрик детекции. Особенно заметно улучшение стабильности предсказаний при сдвигах изображения, где наблюдается увеличение IoU Stability на 6.8-11.1 процентных пунктов. Также значительно снижается дрейф центра ограничивающей рамки (Center Drift) — более чем в 2 раза для метода TIPS.

Для более детального анализа распределения значений IoU при использовании различных методов был проведен статистический анализ, результаты которого представлены на рисунке (см. Рис. \ref{fig:boxplot_iou}).

\subsection{Общее сравнение методов}
\label{ssec:comparison}

Сравнительный анализ результатов показывает, что оба метода антиалиасинга (BlurPool и TIPS) обеспечивают значительное повышение инвариантности к сдвигам как для задач классификации, так и для детекции объектов. При этом метод TIPS показывает более высокие показатели по метрикам стабильности, однако требует несколько больших вычислительных затрат по сравнению с BlurPool.

Преимущества применения методов антиалиасинга:
\begin{itemize}
    \item Повышение точности предсказаний (Top-1 Accuracy, mAP) на 1.3-2.1 процентных пунктов;
    \item Значительное улучшение стабильности предсказаний при сдвигах изображения (на 7.5-11.1 процентных пунктов);
    \item Снижение дрейфа центра ограничивающей рамки в задаче детекции объектов (в 2-3 раза);
    \item Особенно заметное улучшение для объектов малого размера (прирост mAP до 2.6 процентных пунктов).
\end{itemize}

При этом вычислительные затраты увеличиваются незначительно (0.7-4.9\% по FLOPs), что делает данные методы применимыми для широкого спектра практических задач, включая системы реального времени.
